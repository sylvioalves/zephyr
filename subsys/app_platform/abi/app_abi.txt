# Functions the firmware exports to loadable application modules.
#
# Each entry reads <name> <version> <kind> <condition> <return type> (<parameters>) and may
# continue on indented lines. The firmware exports it as app_abi_<name>_v<version>. A "svc"
# entry forwards to the service app_svc_<name>, must match its declaration in app_services.h,
# and is called by a module as app_svc_<name>. A "fw" entry is implemented by the firmware
# itself and is called by a module as app_<name>. The condition is the Kconfig option that
# builds the function, or "-" when it is always built.
#
# A released entry never changes. A new signature or behavior takes a new entry with the next
# version, and the old one stays as a "fw" entry for the modules built against it.
