# Symbols outside app_abi.txt that a loadable application module may import.
#
# Each entry reads <symbol> <architectures>, the architectures being a comma-separated list of
# ARCH names or "-" for every architecture. The loader refuses a module that imports any other
# symbol, and the signer refuses to sign one.
#
# Only pure C library functions belong here, which touch nothing but the memory the caller hands
# them, and the compiler run-time helpers the compiler emits calls to. Each must also be exported
# by the firmware to be linked at all.
